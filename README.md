# About CommerceIQ

**CommerceIQ** is an end-to-end **E-Commerce Analytics Platform** designed to transform raw transactional data into actionable business intelligence.

Instead of being just another dashboard project, CommerceIQ combines multiple analytics layers into one centralized application:

```text
Raw Data
     ↓
Data Cleaning & Validation
     ↓
SQLite Data Warehouse
     ↓
SQL Analytics
     ↓
┌──────────────────────────────────────────────┐
│ Streamlit │ AI Insights │ Power BI │
└──────────────────────────────────────────────┘
     ↓
Actionable Business Decisions
```

The platform brings together:

> **Data Engineering + SQL Analytics + Customer Intelligence + Product Analytics + Business Intelligence + AI-Assisted Insights**

into a single analytics ecosystem.

# RFM Customer Segmentation

CommerceIQ uses **RFM Analysis** to segment customers according to purchasing behaviour.

```text
             ┌─────────────────────┐
             │    Customer Data    │
             └──────────┬──────────┘
                        ▼
             ┌─────────────────────┐
             │     RFM Engine      │
             ├─────────────────────┤
             │ R → Recency         │
             │ F → Frequency       │
             │ M → Monetary Value  │
             └──────────┬──────────┘
                        ▼
                Customer Segments
```

### Generated Segments

| Segment | Business Meaning |
|---|---|
| 🏆 **Champions** | High-value and highly engaged |
| 💎 **Loyal Customers** | Consistent repeat buyers |
| 🌱 **Potential Loyalists** | Customers with loyalty potential |
| ⚠️ **At Risk** | Previously valuable customers losing engagement |
| 💤 **Lost Customers** | Long-term inactive customers |
| 🆕 **New Customers** | Recently acquired customers |

### Business Value

RFM segmentation enables teams to move beyond:

```text
"Who purchased?"
```

and start answering:

```text
"Who should we retain?"
"Who should we reward?"
"Who is at risk?"
"Who should we target next?"
```

# ⚡ Quick Start

## 1️⃣ Clone the Repository

```bash
git clone https://github.com/yourusername/CommerceIQ.git
cd CommerceIQ
```

## 2️⃣ Create a Virtual Environment

### Windows

```bash
python -m venv venv
venv\Scripts\activate
```

### macOS / Linux

```bash
python3 -m venv venv
source venv/bin/activate
```

## 3️⃣ Install Dependencies

```bash
pip install -r requirements.txt
```

## 4️⃣ Launch CommerceIQ

```bash
streamlit run app.py
```

The application will launch locally in your browser.
